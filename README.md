\# 🌴 EravurGo — Local Tourist Day Visit Planner



A web-based tourism platform for discovering destinations within a 25 km radius of \*\*Eravur, Batticaloa, Sri Lanka\*\*.



\## 📋 Project Info



\- \*\*Module:\*\* ITE2953 — 25S2

\- \*\*Student:\*\* Muzaif BM (E2410945)

\- \*\*University:\*\* University of Moratuwa

\- \*\*Version:\*\* 1.0



\## ✨ Features



\- 🔍 Browse and search tourist places

\- 🗂️ Filter by category

\- 🗺️ Google Maps integration

\- 📅 One-day visit planner with distance calculation

\- 📄 PDF export of visit plans

\- ⭐ Reviews and ratings

\- 🔐 Admin panel with CRUD operations

\- 🌙 Dark mode support



\## 🛠️ Tech Stack



\- \*\*Backend:\*\* PHP 8, MySQL

\- \*\*Frontend:\*\* HTML5, CSS3, Bootstrap 5, JavaScript

\- \*\*Libraries:\*\* FPDF, Google Maps API, Chart.js

\## 🚀 Setup Instructions



1\. Clone: `git clone https://github.com/bmmuzaif-tec/tourist-planner.git`

2\. Move to `C:\\wamp64\\www\\`

3\. Import `database/tourist\_planner.sql` in phpMyAdmin

4\. Update `config/db.php` with database credentials

5\. Open: `http://localhost/tourist-planner/`
